# 돈꼬마트 2.0.6 릴리즈 노트

## 새 기능
- **후원하면 바로 감사 연출이 터져요**: 커피·케이크·식사 후원이 완료되는 순간, 콘페티가 흩날리고 감사 카드가 떠오르며 햅틱이 함께 울려요. 개발자의 감사가 바로 전해집니다. (VoiceOver 안내 지원, '동작 줄이기' 켜져 있으면 콘페티 없이 카드만 표시)
- **후원자 감사 리마인더**: 후원해주신 분께는 마트 휴무일에 가끔(1년에 3번 정도) "보내주신 기부의 감사함을 잊지 않았어요"라는 축하 인사를 다시 전해요. 원하시면 그 자리에서 한 번 더 응원할 수도 있어요.

## 개선
- 후원 상품 목록의 이모지 표기를 통일했어요 (☕️🍰🍱).
