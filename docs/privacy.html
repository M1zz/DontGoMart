개인정보처리방침

최종 업데이트: 2026년 10월 8일

요약

돈꼬마트는 계정이 없고 광고나 추적 도구를 쓰지 않습니다. 고른 마트, 직접 추가한 마트, 단골 식당, 알림 설정은 모두 기기 안에 저장됩니다. 개발자가 받는 것은 개인을 알아볼 수 없는 익명 사용 통계와, 직접 보내 주실 때의 피드백뿐입니다.

1. 기기에 저장되는 정보

기능을 제공하기 위해 다음 정보를 기기 안에만 저장합니다. 홈 화면 위젯이 같은 정보를 보여 줄 수 있도록 기기 안의 앱 그룹 영역에 함께 둡니다.

  • 고른 마트와 지역 설정
  • 직접 추가한 마트(이름과 휴무 규칙)
  • 단골 식당(이름, 주소, 정기 휴무, 지도 링크)
  • 알림 설정(며칠 전, 몇 시에 받을지)과 앱 설정

이 정보는 개발자에게 전송되지 않으며, 앱을 삭제하면 함께 지워집니다.

2. 알림

휴무일 알림은 기기 안에서 예약되는 알림입니다. 알림을 위해 서버로 보내는 정보는 없습니다.

3. 사진

식당 정보 화면의 스크린샷으로 휴무일을 채울 때는 사용자가 고른 사진만 받습니다. 사진 속 글자는 Apple의 Vision 기술로 기기 안에서 읽으며, 사진과 읽은 글자는 어디로도 전송되지 않습니다.

휴무 소식 카드의 사진이나 동영상을 앨범에 저장할 때만 사진 보관함에 추가하는 권한을 요청합니다. 보관함의 다른 사진은 읽지 않습니다.

4. 네이버지도 링크로 식당 가져오기

네이버지도에서 공유한 링크를 붙여넣으면, 앱이 그 링크와 해당 식당의 네이버 플레이스 페이지에 직접 접속해 이름, 주소, 정기 휴무를 읽어 옵니다. 이때 일반적인 웹 접속과 마찬가지로 네이버가 기기의 IP 주소 같은 접속 정보를 받을 수 있으며, 이 부분에는 네이버의 개인정보처리방침이 적용됩니다. 이 요청은 개발자의 서버를 거치지 않습니다.

5. 위치 정보

돈꼬마트는 위치 정보를 요청하거나 수집하지 않습니다. 매장은 사용자가 목록에서 직접 고릅니다.

6. 후원(인앱 결제)

커피, 케이크, 식사 후원은 Apple의 인앱 결제로 처리되며, 개발자는 결제 수단이나 결제 정보를 볼 수 없습니다. 후원 횟수와 후원자 배지 표시 여부는 다른 기기에서도 이어지도록 사용자 본인의 iCloud(키-값 저장소)에 저장됩니다. 이 값은 사용자의 Apple 계정으로 보호되며 개발자는 볼 수 없습니다.

7. 공지사항

앱은 개발자가 올린 공지가 있는지 확인하기 위해 Apple CloudKit의 공개 데이터베이스에서 공지를 읽어 옵니다. 이 과정에서 사용자 정보를 보내지 않습니다.

8. 피드백

앱에서 피드백을 보내면 다음 내용이 개발자의 CloudKit 데이터베이스(iCloud.com.Ysoup.FeedbackHub)로 전송됩니다. 답변과 앱 개선에만 사용합니다.

  • 작성한 내용과 피드백 종류
  • 앱 버전, 기기 모델, iOS 버전, 언어와 지역 설정
  • 이름과 이메일(직접 입력한 경우에만, 회신용)

피드백은 직접 보내기를 눌렀을 때만 전송됩니다.

9. 익명 사용 통계

앱이 실제로 어떻게 쓰이는지 알기 위해 개발자의 CloudKit 데이터베이스(iCloud.com.Ysoup.FeedbackHub)로 익명 통계를 보냅니다.

  • 앱을 설치할 때 만들어지는 무작위 설치 번호(이름, Apple 계정, 기기 식별자와 연결되지 않으며 앱을 삭제하면 사라집니다)
  • 앱 버전, iOS 버전, 언어와 지역 설정, 실행 횟수, 설치 후 지난 날 수, 앱을 연 날
  • 추적 중인 마트 수, 직접 추가한 마트 수, 알림을 켰는지와 며칠 전에 받는지, 누적 후원 횟수
  • 공유, 달력 열기, 마트 변경, 나만의 마트 저장, 알림 켜기, 후원 완료 같은 주요 동작의 이름

마트와 식당의 이름, 주소, 링크, 사진, 이름, 이메일, 위치는 보내지 않습니다. 통계는 12시간에 한 번, 동작 기록은 종류마다 6시간에 한 번을 넘지 않습니다.

10. 제3자 제공

광고, 광고 네트워크, 제3자 분석이나 추적 도구를 쓰지 않습니다. 정보는 위에 적은 Apple 서비스(CloudKit, iCloud, 인앱 결제, 기기 안의 기능)와, 사용자가 링크를 붙여넣었을 때의 네이버 접속으로만 처리됩니다. 개인정보를 판매하거나 제3자와 공유하지 않습니다.

11. 보관과 삭제

기기에 저장된 정보는 앱 안에서 지우거나 앱을 삭제하면 사라집니다. iCloud에 저장된 후원 기록은 기기의 설정에서 Apple 계정, iCloud 순으로 들어가 관리할 수 있습니다. 보낸 피드백의 삭제를 원하시면 아래 이메일로 요청해 주세요.
