# 돈꼬마트 2.0.5 릴리즈 노트

## 버그 수정
- **나만의 마트 선택이 풀리던 문제 수정**: 나만의 마트 스위치를 껐다가 다시 켜면 겉으로는 켜진 것처럼 보여도 실제로는 선택이 해제되어, 내가 설정한 휴무일이 메인 화면·위젯·알림에 반영되지 않던 문제를 고쳤어요.
- **후원 상품이 계속 "불러오는 중"으로 남던 문제 수정**: 설정 화면과 후원 카드에서 후원 상품 목록이 표시되지 않던 문제를 수정했어요.
- 나만의 마트를 삭제해도 내부에 선택 기록이 남던 문제를 정리했어요.

## 개선
- **후원 카드가 나만의 마트 휴무일에도 표시돼요**: 앱이 헛걸음을 막아준 날이라면, 직접 설정한 마트의 휴무일에도 응원 카드를 만날 수 있어요. (물론 "다음에"를 누르면 30일간 다시 묻지 않아요)
