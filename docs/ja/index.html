出かける前に、
お店が開いているか確認

DontGoMartは、韓国の大型スーパーやコストコの義務休業日を確認し、休業日の前にお知らせするアプリです。お気に入りの飲食店の定休日も管理できます。

主な機能

🛒

今日の営業状況がひと目でわかる

アプリを開くと、選んだお店が今日営業しているかが真っ先に表示されます。次の休業日までの日数と、今後の休業日の一覧も確認できます。

🗺

地域ごとの休業日に対応

日曜休業や水曜休業のお店のほか、蔚山や済州のように休業日が異なる地域も選べます。コストコの大邱店・一山店・蔚山店は個別に設定でき、旧正月と秋夕の休業日も表示されます。

➕

近所のお店を追加

一覧にないお店は、第2・第4日曜日のように、何週目の何曜日に休むかを選んで自分で登録できます。

🍜

お気に入りの飲食店も

Naverマップの共有リンクを貼り付けるか、お店の情報画面のスクリーンショットを選ぶだけで、定休日が自動で入力されます。写真の中の文字は端末の中だけで読み取ります。

🔔

生活に合わせた通知

休業日の1日前・2日前・3日前・7日前から選び、好きな時刻に通知を受け取れます。前日には「今日は買い物にぴったりの日」とお知らせするオプションもあります。

📱

ホーム画面・ロック画面のウィジェット

直近の休業日までのカウントダウン、今週の日曜日が休業かどうか、飲食店の今後7日間の休みを、アプリを開かずに確認できます。

📅

カレンダーと共有

1か月分の休業日をカレンダーで確認し、2週間分のカレンダー付きのカードや短い動画にして共有できます。

すべての機能が無料

閉まっているお店の前で引き返すことは、もうありません。
