## About

Klosed는 한국 대형마트의 의무 휴무일을 추적하는 iOS 앱입니다. 위젯과 알림으로 헛걸음을 방지하세요.

### Features

- **휴무일 추적** - 대형마트, 코스트코 지점별 의무 휴무일 자동 계산
- **홈 화면 위젯** - D-Day 카운트다운 위젯으로 한눈에 확인
- **스마트 알림** - 휴무 3일 전, 1일 전 알림
- **다중 마트 추적** - 여러 마트를 동시에 관리 (Pro)
- **커스텀 매장** - 나만의 마트 휴무 패턴 등록 (Pro)
- **장보기 목록** - 간편한 장보기 체크리스트

## Tech Stack

- **SwiftUI** + WidgetKit
- **StoreKit 2** (In-App Purchase)
- iOS 17.6+
